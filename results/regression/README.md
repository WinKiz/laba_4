# Повторная проверка отключения R1

Окончательная версия: отдельный CountDownLatch для обработки каждого ID, TCP shutdownOutput у получателя, удаление соединения из LocalBroker до ответного закрытия.

Проверен сценарий 2 с обычными параметрами задания: 1000 сообщений, R1 закрывается после 250, R2 получает 750, общий дедлайн 10 секунд. Выполнены 1 прогрев и 30 основных измерений — все 31 запуска PASS, без пропусков, дубликатов, неизвестных ID и повреждённых текстов. После завершения рабочих потоков не осталось.

Полные исходные значения: measurements.csv, распределение каждого запуска: shares.csv, среда: environment.txt. Эта проверка не подмешана в медианы основной серии results/local, где у каждого эксперимента ровно 5 основных измерений.

Неуспешные диагностические запуски старого варианта сохранены в ../diagnostics. Увеличения обязательного 10-секундного лимита для получения PASS не применялось.

## Проверка завершения потоков — 18 ноября 2026

В пользовательском полном запуске все 90 проверок доставки были PASS, но итог был FAIL: environment.txt зафиксировал 10 живых потоков после закрытия. Отдельный запуск через Main завершился PASS. В старом варианте ожидалось завершение ExecutorService, после чего сразу проверялась жизнь потоков. Завершение исполнителя может предшествовать фактическому выходу его рабочего потока.

Добавлен ThreadSupport: после остановки исполнителя ожидается выход каждого созданного им потока через join с общим ограничением времени. Проверка не отключена: действительно зависший поток приводит к ошибке. При ненулевом итоговом числе потоков Main дополнительно сохраняет имена, состояния и стеки в threads-after-close.txt.

Новый самостоятельный тест удерживает поток после завершения исполнителя: пока поток удерживается, остановка обязана считаться неуспешной; после освобождения join должен дождаться его выхода. Всего 29 тестов, все прошли как через build.ps1, так и через Maven package. Все 7 проверок командной строки также прошли.

Новая полная серия находится в shutdown-2026-11-18: 15 конфигураций, у каждой 1 прогрев и 5 измерений, всего 90 PASS. После закрытия 0 потоков, ошибок протокола 0. Проверялся вспомогательный локальный брокер на Windows/JDK 23 с компиляцией для Java 21. Исходные пользовательские папки my-run и run-1795008399957 сохранены без изменений. Основная серия results/local не заменена новыми числами.
